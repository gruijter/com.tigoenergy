# Free Tigo API access for EU users

The Tigo app for Homey uses the Tigo cloud API. Normally that needs an EI Premium subscription.

Under the **EU Data Act** you have the right to free access to the data your own system produces.

## How to ask

1. Go to https://support.tigoenergy.com/hc/en-us/requests/new
2. Send a request like this. Fill in your Tigo account e-mail and your system name. You can find the system name in the Tigo EI app or after logging in at https://ei.tigoenergy.com

```text
Subject: Free API access under the EU Data Act

Hello,

I live in the EU and own a Tigo system. Under the EU Data Act (Regulation (EU) 2023/2854, Article 4) I request free access to the data of my system through the Tigo API.

Account e-mail: ...
System name: ...

Please activate API access for my account.

Thank you.
```

3. When Tigo confirms, add or repair the Tigo device in Homey.

## Good to know

- Not guaranteed: Tigo may handle each request differently.
- It is not yet known how often the data updates with free access (every minute or every 15 minutes).
- Please share Tigo's answer in this topic so others know what to expect.
